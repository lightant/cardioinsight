# Cardio Insight (Flutter)

A native Flutter application for heart rate monitoring and health insights, migrated from the original Capacitor/React project.

## Features

- **Health Connect Integration**: Sync heart rate data directly from Android Health Connect.
- **Heart Rate Visualizations**: Dynamic charts showing daily, weekly, and monthly trends using `fl_chart`.
- **AI-Driven Insights**: Personalized health reports generated by Google Gemini API.
- **State Management**: Robust data handling with Riverpod.

## Setup

1. **Flutter Installation**: Ensure you have [Flutter](https://docs.flutter.dev/get-started/install) installed on your machine.
2. **API Key**: 
   - Open `lib/views/insight_view.dart`.
   - Replace `'YOUR_API_KEY'` with your actual [Google Gemini API Key](https://aistudio.google.com/app/apikey).
3. **Dependencies**:
   ```bash
   flutter pub get
   ```

## Running the App

To run the app in debug mode on a connected device or emulator:

```bash
flutter run
```

## Building and Compiling

### Android

To build an APK for testing or distribution:

```bash
flutter build apk --release
```

To build an App Bundle for the Play Store:

```bash
flutter build appbundle
```

### iOS

To build the iOS runner:

```bash
flutter build ios --release
```
Note: Building for iOS requires macOS and a valid Apple Developer Account configured in Xcode.

## Architecture

- `lib/models`: Data structures for records and user profiles.
- `lib/providers`: State management logic using `Notifier`.
- `lib/services`: External integrations (Health, AI).
- `lib/views`: UI screens and navigation logic.
- `lib/widgets`: Reusable UI components like the Heart Rate Chart.
